DAW Cordova App Launcher

Launch your DAW Cordova app with one click. The launcher detects running servers and provides clear guidance for each option.

ℹ️ Quick Start & Troubleshooting

  • Option 1: Opens the HTML file directly from E:/DAW-Cordova/www
  • Option 2: Use if you started a server with python -m http.server 8080
  • Option 3: Use if you started a Node.js server on port 3000
  • If a button is disabled, the server is not detected or the file is unavailable.
  • If nothing opens, check your firewall, server status, or file path.

T-Dubs Duplicate Destroyer

Windows desktop app · v1.0 · free

Find true duplicate files by content, compare them side-by-side, and clear them safely — plus a new tab that finds and restores missing and misplaced files.

Unzip, then run Launch T-Dubs Duplicate Destroyer.bat (Windows) or python T-Dubs_Duplicate_Destroyer.py.

✨ New: Missing File Reconciler tab 2

Point it at a Reference folder (your complete copy) and a Target folder (the incomplete one). It streams findings live and color-codes them: missing, misplaced (a copy exists elsewhere), different, and only-in-target — then copies missing files into place on your say-so. It only ever copies: it never moves or deletes, and never overwrites an existing file.

What it does

  • Duplicate Destroyer tab — scans any drive, folder, or repo and finds true duplicates by content (size + SHA-256), not just by name.
  • Side-by-side A/B compare with a verdict (identical / different) before you remove anything.
  • Safe deletes — "to Recycle Bin (recoverable)" is on by default; "Keep newest / oldest" always leaves one copy.
  • Move, copy, run, open location, and export results to CSV / HTML / TXT.
  • Missing File Reconciler tab — find and restore missing / misplaced files, copy-only and non-destructive.
Your data is protected. Deletes default to the Recycle Bin so they're recoverable, and the Reconciler never deletes or overwrites anything. A first run on a small, non-critical folder is a good way to get comfortable.

What it does

  • Scan any drive, folder, repo or location
  • Search each folder separately (optional)
  • Finds true duplicates by content, not just name
  • Side-by-side BOX A vs BOX B compare
  • Compares sizes, dates, and content verdict
  • Multi-select with keep-newest / keep-oldest
  • Recycle Bin (recoverable) or permanent delete
  • Move, copy, run, open location, share results
  • Drag & drop folders to scan / files to compare
  • Export results to CSV, HTML, or TXT

How to run it

🖥️ Windows

  1. Download the .exe above.
  2. Double-click T-Dubs-Duplicate-Destroyer.exe.
  3. If SmartScreen appears: More info → Run anyway (it's unsigned, but it's your own app).

🍎 macOS / Linux

  1. Install Python 3 from python.org (if not already installed).
  2. Unzip the source download.
  3. Run python3 T-Dubs_Duplicate_Destroyer.py.
Heads up: this is a full desktop tool that needs direct access to your files, so it runs on computers (Windows, macOS, Linux) — not on phones or tablets, which sandbox apps away from the file system. The Recycle Bin option keeps deletes recoverable on Windows.
